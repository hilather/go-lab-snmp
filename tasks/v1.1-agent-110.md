# AGENT-110 — TCP + DTLS agent

Status: not-started
Depends: CFG-110, WIRE-110, APP-110
Owns: internal/snmpagent, go.mod pion pin, NOTICE MIT line

## Goal
RFC 3430 TCP and DTLS 1.2 record layer on the agent plane.

## Scope
- `Listen` + Accept for TCP; pion `ListenWithOptions` for DTLS
- AEAD `WithCipherSuites` (K1.21); fail closed if option absent
- `WithOnConnectionAttempt(func(net.Addr) error)` against **live**
  snapshot CIDRs
- HandshakeContext error → Close, no handle
- `replySink`; `MaxAcceptedConns = 1024` including in-handshake
- Extend `dataPlane.Sync` with agent TCP/DTLS binds from cmd
- pion/dtls v3 **v3.1.8** or newer patch `govulncheck` accepts
- `make security-scan` is a **merge gate**

## Non-scope
`dtls.Dial` in production files. TSM. TLS-over-TCP. New USM algs.
`internal/snmpdtls`. Trap plane (TRAP-110).

## Tests
TCP GET/GETNEXT/SET same overlay as UDP; unknown community drop; v3;
skip-if-missing `snmpget tcp:`; TCP-only (UDP off); DTLS GET ≥8KiB
octet-string; UDP/DTLS same-addr validate reject; first-party DTLS
client (not net-snmp `-T dtlsudp`). Dial AST green.

## Acceptance
Never `InsecureSkipVerifyHello`. Never deprecated `dtls.Listen` /
`*dtls.Config`. Import pion only from snmpagent/snmpsink and tests.
