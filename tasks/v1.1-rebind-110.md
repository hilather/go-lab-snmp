# REBIND-110 — UDP SyncDataPlane (U2)

Status: not-started
Depends: none (parallel to FND-110 / BUG-110). Does not need CFG/pion.
Owns: cmd/labsnmp dataplane hook, internal/app DesiredListeners (UDP),
  UDP bind helpers on snmpagent/snmpsink

## Goal
Reset rebinds UDP agent and trap sockets. This is the U2 fix and must
not wait for DEP-110.

## Scope
- `DesiredListeners` in `internal/app`. Empty address = off.
- `SetDataPlaneSync(func(desired DesiredListeners) error)`
- `resetLocked` fills UDP fields from **`next`** + `effectiveSNMP` /
  `effectiveTrap` and calls the hook **before** Swap
- Cmd `Sync` only binds — never `Active()`
- Bind-all-new, rollback on failure, then close removed
- Empty desired UDP addr **stops** the socket
- Retire serve’s missing `SetSNMPRebind` wiring (keep old setters
  until `reset_test.go` switches)

## Non-scope
TCP/DTLS fields (empty until APP-110). pion. CFG validate flip.

## Tests
Bootstrap `agent.address` change + Reset moves the PacketConn. Failed
new bind leaves old sockets serving.

## Acceptance
K1.17 UDP-only. A zero-arg `SetDataPlaneSync(func() error)` is
forbidden.
