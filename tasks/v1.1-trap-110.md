# TRAP-110 — TCP + DTLS trap/inform transport

Status: not-started
Depends: BUG-110, WIRE-110, APP-110, AGENT-110 (pion already in go.mod)
Owns: internal/snmpsink

## Goal
TCP/DTLS trap/inform on the sink plane. One `ack(sink)` for INFORM
and Report.

## Scope
- Store then ack (ADR 0007)
- BER `WriteTCP` / DTLS `Write` on the accepted conn
- TRAPv1 / SNMPv2-TRAP: store, no reply
- Extend Sync with trap TCP/DTLS
- Cap accepted conns including in-handshake (K1.18)

## Non-scope
Dial. New pion pin (AGENT-110 owns go.mod). Trap forward/originate.

## Tests
INFORM over TCP BER Response; v3 Report on same `ack(sink)`; TRAPv2
store; Dial AST.

## Acceptance
Never Dial. INFORM/Report share one ack path.
