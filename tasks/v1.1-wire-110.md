# WIRE-110 — RFC 3430 BER stream framing

Status: not-started
Depends: none strictly; land after FND-110
Owns: internal/snmpwire

## Goal
`ReadTCP` / `WriteTCP` frame one BER SNMP message. No 32-bit prefix.

## Scope
- `snmpwire.ReadTCP` / `WriteTCP` (K1.5)
- Golden of a framed Get starts with `0x30`
- Framing loss: truncated, indefinite length, oversize → error;
  caller closes
- `FuzzReadTCP`
- docs/02 transports row

## Non-scope
pion. Dial. `internal/snmptrans`. PDU dispatch.

## Tests
Round-trip Get first byte `0x30`; truncated BER; indefinite length;
oversize; fuzz; **no** 32-bit prefix golden. Skip-if-missing
`snmpget … tcp:` is the interop contract (AGENT-110 runs it).

## Acceptance
A 4-byte prefix is not named RFC 3430. `snmpwire` stays dep-free.
