# Contributing

1. Read `AGENTS.md`.
2. Take a task from `tasks/00-program-board.md` only when dependencies are done.
3. Do not invent capability IDs, YAML keys, or package paths.
4. Update docs in the same change.
5. CI must pass. Failures are hardened, not retried away.
6. Invariants change only via ADR.
