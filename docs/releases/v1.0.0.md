## Highlights

Laboratory SNMPv1/v2c/v3 agent with a receive-only trap/inform sink.
YAML OID maps per community and per USM user, SET overlay, REST `/v1`,
MCP `snmp_*` / `labsnmp://`, operator SPA (Mira signed off), scratch
image UID 65532. Tag-triggered GHCR `ghcr.io/hilather/labsnmp`.
TLS-001 (DTLS / TCP SNMP) stays deferred.

## Added

- First-party BER codec, bounded v3 USM (MD5/SHA-1/SHA-256 + DES/AES-128),
  UDP/161 GET/GETNEXT/GETBULK/SET, UDP/162 trap/inform sink (INFORM
  `WriteTo`, never Dial).
- Fail-closed `labsnmp.dev/v1alpha1` YAML, plan/apply/reset, REST/MCP
  parity, bearer + cookie `labsnmp_session` + CSRF `X-LabSNMP-CSRF`.
- Operator SPA at `GET /` when `spec.ui.enabled` is true; 404
  `application/problem+json` when false. Mira checklist signed off.
- Integration-lab BOM under `examples/`. Residual host ports
  10161/10162/18161. Env `LABSNMP_REST_PORT`.
- GA fuzz (BER + OID + INTEGER + community encode) and soak
  (GETNEXT+SET+trap). `make security-scan` is govulncheck.
- Tag-gate + GHCR publish on `v*` (`scripts/release-gate`,
  `.github/workflows/release.yml`).

## Residual

- Not a production agent. Not snmpd. Not a manager.
- No SMIv2 compiler. Numeric OIDs + optional aliases.
- v3 algs: MD5/SHA-1/SHA-256 + DES/AES-128 only.
- TLS-001 stays deferred: `spec.listeners.dtls.enabled: true` and
  `spec.listeners.tcp.enabled: true` still reject (`tls_unsupported`).
- No AgentX. No trap forward or originate.
- Trap remoteAddr is best-effort under Docker userland-proxy
  (NAT collision does not affect split-horizon; identity is community/user).
- Single replica. Memory store only.
- No OAuth PRM.
- linux/arm64 is not in this tag.
- Integrator pin in mcp-integration-lab is out of band.

See [docs/known-limitations.md](../known-limitations.md).

## Deployment and operations

Image `ghcr.io/hilather/labsnmp:v1.0.0` and `sha-<7 hex>`. Digest is
the integrator pin. Scratch, UID 65532, HEALTHCHECK exec form, CMD
`--management-listen=:8088`. Host residual 10161/udp, 10162/udp,
18161/tcp. Appliance smoke uses `:1161`/`:1162` with `cap_drop: ALL`.

Do not git tag until required CI jobs on the exact SHA are green.
