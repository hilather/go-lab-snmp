# ADR 0014 — Host residual 10161/10162

Status: Accepted
Date: 2026-09-04

## Context

Numbered docs 00, 01, 11, and 13 already freeze residual host publish
ports `10161/udp` (agent), `10162/udp` (traps), and `18161/tcp`
(management). The ADR index cited this decision but the file was
missing. Native container binds remain IANA `:161`/`:162`.

161 is often held by `snmpd` on lab hosts. Residual high ports are
the default profile publish, not the in-container listen address.

## Decision

Default host publish is **10161/udp**, **10162/udp**, and **18161/tcp**.
The process inside the container still binds `:161`/`:162` (and
management `:8088` when the image CMD turns it on). Local escape is
`:1161` / `:1162` with `cap_drop: ALL`. Integrator compose adds
`NET_BIND_SERVICE` only because the process binds IANA dests inside
the container.

This ADR records an already-accepted decision. It does not change
behavior.

## Consequences

- Appliance tests and `compose.smoke` use 1161/1162, not 10161/10162.
- Integrator overlay publishes 10161/10162/18161.
- Changing residual ports later requires another ADR.
